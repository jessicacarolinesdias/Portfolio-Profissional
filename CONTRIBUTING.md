# Sugestões e contribuições

Sugestões sobre clareza, navegação, documentação e apresentação dos projetos são bem-vindas.

## Como participar

1. Consulte a apresentação do projeto e o [plano de evolução](ROADMAP.md).
2. Verifique se já existe uma [Issue](https://github.com/jessicacarolinesdias/Portfolio-Profissional/issues) sobre o assunto.
3. Registre uma sugestão de melhoria ou um problema de navegação com o formulário correspondente.
4. Informe a página, o comportamento observado e a mudança proposta. Capturas podem ajudar quando contiverem apenas informações adequadas à publicação.

O conteúdo deste repositório é público. Exemplos devem usar dados fictícios e materiais que possam ser divulgados. Para uma possível exposição de dados ou credenciais, utilize a orientação em [SECURITY.md](SECURITY.md).

Alterações propostas devem preservar a distinção entre capturas reais, ilustrações, entregas produzidas e resultados medidos. Os direitos sobre os materiais seguem o aviso em [COPYRIGHT.md](COPYRIGHT.md).
